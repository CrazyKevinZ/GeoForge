简介

GeoForge 是一款专注于 GIS/CAD 数据坐标正确可用 的桌面转换工具。支持在 GeoJSON / JSON / CSV / (OV)TXT / KML / OVKML / GPX / DXF / OSM / XML 等格式之间互转， 转换过程带实时进度与时间估算，专为 kistom 在线预览 与 奥维互动地图 / JOSM / Google Earth 优化。

核心功能

  • 10 种格式互转：GeoJSON / JSON / CSV / (OV)TXT / KML / OVKML / GPX / DXF / OSM / XML
  • 坐标换算：DXF / DWG → 经纬度格式自动按 CGCS2000 高斯-克吕格 3° 带换算为 WGS84，坐标精准
  • 一键预置参考点：Z29 / Z30 / Z35–Z40，快速选择 3° 带中央经线
  • 实时进度：进度条百分比 + 已用时间 + 剩余时间，转换中可取消
  • 完整路径提示：完成弹窗显示所有输出文件完整路径，可一键打开输出目录
  • 绿色单文件：无需安装 Python 或任何依赖，双击即可运行，图标内嵌 exe

快速开始

  1. 选择源文件（支持的文件可直接拖入窗口）
  2. 源为 DXF/DWG 时，填写 参考经纬度（或点 Z 按钮预置 3° 带中央经线）
  3. 点击需要的 目标格式徽章
  4. 点击下方「开始估算」查看输出大小，「开始转换」执行转换
  5. 完成弹窗显示输出文件完整路径，一键打开输出目录
